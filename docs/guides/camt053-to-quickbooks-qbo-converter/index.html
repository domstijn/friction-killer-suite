Convert ISO 20022 CAMT.053.001.02 / .08 XML to QuickBooks .QBO Locally

Step-by-step guide to converting EU ISO 20022 CAMT.053 bank statements into QuickBooks Web Connect (.qbo) in Chrome with zero bank file uploads.

Exact Symptom

European banks export ISO 20022 CAMT.053 XML statements instead of QuickBooks .QBO Web Connect files, forcing firms toward $180-$599/yr third-party SaaS converters.

Technical Root Cause

QuickBooks Desktop and several legacy ledgers require OFX 1.02 SGML wrapped as .qbo with explicit debit/credit signage (<TRNAMT>), <DTPOSTED> YYYYMMDD timestamps, and valid Intuit headers.

CAMT.053 XPath NodeQuickBooks .QBO ElementTransformation Rule
Stmt/Acct/Id/IBAN<ACCTID>Preserves IBAN digits (fallback <Othr><Id>)
Ntry/Amt + CdtDbtInd<TRNAMT> & <TRNTYPE>DBIT negates to negative cents + DEBIT; CRDT stays positive + CREDIT
Ntry/BookgDt/Dt<DTPOSTED>Strips hyphens YYYY-MM-DD -> YYYYMMDD
TxDtls/RltdPties + RmtInf/Ustrd<NAME> + <MEMO>Extracts counterparty name (32 chars) & full reference

Verified Format / Code Snippet

<Ntry>
  <Amt Ccy="EUR">2500.00</Amt><CdtDbtInd>CRDT</CdtDbtInd>
  <NtryDtls><TxDtls>
    <AmtDtls><TxAmt><Amt Ccy="EUR">1500.00</Amt></TxAmt></AmtDtls>
    <RltdPties><Dbtr><Nm>Acme GmbH</Nm></Dbtr></RltdPties>
    <RmtInf><Ustrd>Invoice 2026-101</Ustrd></RmtInf>
  </TxDtls></NtryDtls>
</Ntry>

Step-by-Step Local Resolution

  1. Step 1: Export your statement in CAMT.053 (.xml) format from your online banking portal.
  2. Step 2: Load it into BankFeedBridge (or run `camt053-mt940-qbo-xero-converter` CLI locally on a folder of XMLs).
  3. Step 3: Download the verified .qbo file and import via File -> Utilities -> Import -> Web Connect Files in QuickBooks.
