Exact Symptom

QuickBooks and Xero treat each bi-weekly Amazon payout as net sales, understating gross turnover, hiding FBA/referral fees, and breaking VAT reconciliation.

Technical Root Cause

Each Amazon bank deposit is a net sum of dozens of Settlement Report V2 transaction types (`Principal`, `Commission`, `FBAPerUnitFulfillmentFee`, `Reserve`).

Amazon V2 Transaction TypeLedger DirectionAccount Bucket Mapped
Principal / Product ChargesCredit (+)Amazon Gross Sales Revenue
Commission / FBA / Storage FeesDebit (-)Marketplace Selling & Fulfillment Fees
Tax / MarketplaceFacilitatorVATSeparate Tax LineSales Tax / VAT Clearing
Previous/Current Reserve AmountBalance Sheet AssetAmazon Seller Reserve Clearing (Net Sum = Deposit)

Step-by-Step Local Resolution

  1. Step 1: Download Settlement Report V2 (Flat File V2) from Amazon Seller Central -> Payments -> All Statements.
  2. Step 2: Load the TSV/TXT locally in AmzSettlementBridge to verify `Gross - Fees - Reserves == Bank Deposit`.
  3. Step 3: Export balanced Xero Manual Journals or QuickBooks IIF/CSV—no A2X per-order monthly tax.
