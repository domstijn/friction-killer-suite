How to Fix BZSt Mein BOP OSS CSV Import Errors ('GR' vs 'EL', Semicolon Delimiter & Refunds)

Solve German BZSt Mein BOP EU-OSS CSV upload rejections caused by ISO country code GR (Greece -> EL), comma vs semicolon delimiters, B2B rows, and refunds.

Exact Symptom

Uploading a Stripe or Shopify VAT export directly into Germany's BZSt Mein BOP portal fails with invalid Member State codes ('GR') or rejected row syntax.

Technical Root Cause

Stripe and Shopify output ISO 3166 country code `GR` for Greece, whereas EU VAT OSS schemas (BZSt BOP & Ireland ROS) require `EL`; BOP also requires semicolon (`;`) rows stripped of domestic, non-EU, and B2B reverse-charge sales.
