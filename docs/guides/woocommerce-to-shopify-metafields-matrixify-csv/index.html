Exact Symptom

Uploading a standard WooCommerce Product Export CSV directly to Shopify drops Attribute 4+, disconnects variations (`id:101` vs SKU), ignores Yoast SEO titles, and breaks Google rankings without 301 redirects.

Technical Root Cause

Shopify enforces a hard 3-option limit on native variants and expects Matrixify `Metafield:` / `Variant Metafield:` headers plus strict Handle continuation rows with parent-only fields blanked.
