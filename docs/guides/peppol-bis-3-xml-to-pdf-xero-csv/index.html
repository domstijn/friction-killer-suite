Exact Symptom

Suppliers over Peppol deliver raw UBL 2.1 XML files that bookkeepers cannot easily read or bulk-import into Xero / QuickBooks as itemized bills.

Technical Root Cause

Peppol BIS 3.0 enforces EN 16931 UBL tags (`InvoiceLine`, `TaxCategory`, `AccountingSupplierParty`) designed for machine-to-machine ERP ingestion rather than human inspection.
